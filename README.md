# Project Xbox Sales Dashboard with Excel

The goal of this challenge is to create a sales dashboard, focusing on data organization and visualization. The objective is to transform raw data into clear, useful visual information, enabling effective analysis of sales performance and data-driven decision-making.

## Functions or tools used:
 
 - Data Segmentation: It is a visual tool that allows you to filter tables, pivot tables, and charts in a quick, interactive, and dynamic way.
 - PivotChart: it is a visual representation that automatically adapts and changes based on data from a Pivot Table or applied filters
 - PivotTable: It is an Excel tool used to summarize, calculate, and analyze large volumes of data quickly, without the need to type complex formulas.
 - Data Cleaning: Transforms messy, unorganized spreadsheets into clean, structured data ready for analysis
